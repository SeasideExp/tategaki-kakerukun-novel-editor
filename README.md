## 0. はじめに

このテキストエディタは、作者（しーさいど）が既存のテキストエディタの仕様に納得行っていなかったので自分で作ったものです。テキストエディタ作成にあたってはＡＩを全面活用しています（Google Gemini4Argon）。「本文を書き出す」事のみを想定しており、同人誌として仕上げる場合、表紙や挿絵は別のソフトを使う想定です。そのため、オールインワンではないのは仕様となっています。

## 1. 概要・データ保持・プライバシー仕様について

### ■ 概要
「縦書き同人小説書けるくん」は、ブラウザ上で縦書きの右綴じ見開きプレビューをリアルタイムに確認しながら小説を執筆し、印刷所入稿・DTP編集向けの **全ページ連番PSD (ZIP一括)** / **全ページ連番PNG (ZIP一括)** や各種テキストファイル（プレーンテキスト / 青空文庫形式 / Markdown / CSV）を出力できる同人小説執筆特化エディタです。

外部サーバーやビルド環境を必要とせず、`index.html` をブラウザで開くだけでそのまま動作します。

### ■ データの保持と「セーブ」の推奨について（重要）
執筆中の原稿や設定内容は、お使いのブラウザ内のストレージ（`localStorage`／ブラウザキャッシュ領域）に自動的に保持される仕組みになっており、ページを再読み込みしても続きから作業できます。

ただし、ブラウザ内のキャッシュ領域で保持しているため、**ブラウザの「キャッシュ・閲覧データ削除（サイトデータの消去）」を行ったり、シークレット（プライベート）ウィンドウを閉じたりすると、保持されていたデータが消えてしまう恐れがあります**。  
大切な原稿の消失を防ぐため、画面右上の **「セーブ」ボタン（初期ショートカット: `Ctrl+S`）** から、こまめにCSVファイルとしてPC等のローカル環境へ保存しておくことを強く推奨します。

### ■ AI非学習・外部へのデータ非送信について
本ツールは、文字入力・組版計算・プレビュー描画・ファイル入出力を含むすべての処理を、**お使いのブラウザ内（ローカル環境）のみで完結させる仕様**です。  
執筆した小説本文や設定データが外部のサーバーへ送信されることは一切なく、AIの学習データとして利用・収集されることもありません。安心して執筆にご利用いただけます。  
（※Webフォント表示用の Google Fonts スタイルシート読み込みのみインターネット接続を利用しますが、オフライン環境でもPC内のシステムフォントでそのまま動作します）

### ■ 起動方法
1. 本リポジトリをダウンロード（または `git clone`）します。

## 3. 画面構成と基本操作

### ■ 上部ヘッダー
- **このツールについて / ヘルプ**：
  - ツール情報（バージョン・最終更新日・著作権表記）および機能ガイド（別窓）を表示します。
- **日付・経過ゲージ・締切ゲージ**：
  - 現在の日付（西暦・月日・曜日）、今日／今月の経過率（%）、および設定した締切日時までの残り時間（%）をリアルタイムでゲージ表示します。
  - 「締切未設定（または締切ゲージ）」をクリックすると別窓が開き、締切年月日・時刻を設定できます。ゲージは残り時間に応じて通常色 → 50%未満（注意色） → 20%未満（危険色）へ変化します。
- **全ページ合計カウンター（文字数カウントの基準）**：
  - 「純粋文字数」「空白・改行除外」「実文字数（ルビ・制御記法除外）」「400字詰原稿用紙換算枚数」をリアルタイム集計します（「UI設定」タブから各表示のON/OFF切替が可能。「400字詰換算」は初期状態で非表示）。
  - 全ページ合計の各数値は、**各ページの文字数を単純合算した値**です（ページの切れ目自体は文字数には加算されません）。
    - **「純粋文字数」**：改行・空白・ルビ記法・制御タグを含むすべての文字数。
    - **「空白・改行除外」**：全角/半角スペース・タブ・改行を除いた文字数。
    - **「実文字数」**：ルビ文字（`《》` 内および `｜` 記号）と制御タグ（`[改ページ]`・`[改丁]`・`[縦中横:...]` のタグ枠等）および空白・改行を除いた、実際に組版される本文の実質文字数。
- **セーブ / ロード**：
  - 右上の「セーブ」（初期ショートカット: `Ctrl+S`）で全ページの原稿データをCSVファイルとして保存、「ロード」で保存した本文CSVファイルを読み込みます（誤読込防止の確認ダイアログ付き）。

### ■ 左ペイン：執筆エディタ
- **境界バー（スプリッター）のドラッグ調整**：
  - エディタとプレビューの間の境界線（中央の縦線）をドラッグして任意の幅比率に調整できます（ダブルクリックで標準幅にリセット）。
- **ページ属性表示**：
  - 現在表示中ページの属性（「本文」「扉」「目次」「空白」）を表示します。
- **本文連動区間**：
  - 連続する「本文」ページ（間に「空白」ページを含む場合も連動維持）は1つの連動区間として繋がっており、文字の入力・削除に応じて自動でページが増減・折り返しされます。
  - 章ごとに独立させたい場合は「✂カーソル位置で連動を区切る」「＋新規連動区間を追加」等で区間を分けられます。
- **執筆補助ツールバー**：
  - 「元に戻す (`Ctrl+Z`)」「ルビ挿入」「縦中横」「ダッシュ (`――`)」「三点リーダー (`……`)」「`[改ページ]`」「`[改丁]`」のワンクリック挿入、および本文内キーワード連続検索（エディタ選択＆プレビュー上のハイライト表示）が可能です。
  - **「元に戻す (`Ctrl+Z`)」の対象範囲**：本文の入力・削除やページの追加・削除・並替だけでなく、**環境・組版設定の変更、扉ページの入力、目次項目の追加・削除・編集、ファイル読み込み操作**にも対応しています。
- **エディタ下部チェック機能**：
  - **「割付ページ別の背景色表示」**：ONにすると、テキストエリア内でどこからどこまでが何ページ目（`P.1`, `P.2`...）に入るかを交互の背景色と右端のページ境界バッジで視覚化します（デフォルトOFF）。
  - **「文頭1字下げチェック」**：段落先頭の全角空白（`　`）忘れを自動検知し、該当行のハイライト警告や「次の未字下げ行へジャンプ」が行えます（ページ跨ぎの折り返し行は自動除外）。

### ■ 中央ペイン：プレビュー表示
- **見開きプレビュー**：常時「右綴じ見開き」（左＝奇数頁、右＝偶数頁）で実際の製本イメージを確認できます。
- **単ページ表示**：現在編集中の1ページを大きく表示します。
- **9ページグリッド（D＆D入替）**：3×3のグリッドで9ページ分を俯瞰し、ドラッグ＆ドロップでページ順序を直感的に入れ替えられます。
- **ページ送り**：`◀`（次のページへ進む） / `▶`（前のページへ戻る）ボタン、またはプレビュー操作時のキーボード `←` / `→` キーでページ送りが可能です。

### ■ 下部ドック：ページ管理（クリックで開閉）
- ページの追加（`+ 本文頁を追加` / `+ 扉頁を追加` / `+ 目次頁を追加` / `+ 空白頁を追加`）、前後の順序入替、複製、削除が行えます。
- **選択ページ計 ＆ カウンター対象ページ選択**：
  - サムネイル左上のチェックボックス（または「全ページ選択」「現在の頁のみ選択」「選択解除」）で選択したページだけの文字数合計を「選択ページ計」に算出できます（初期状態は未選択）。

## 4. 4つのページ属性について

1. **「本文」**：小説本文を流し込む標準ページです。
2. **「扉」**：小説タイトル（表題）・サブタイトル・著者名・備考を配置するページです。
   - 表題・サブタイトル・著者名の上下位置（天からの距離 mm）や左右位置（横微調整 mm）を数値で微調整できます。
   - ここに入力した「小説タイトル」は、奇数ページのヘッダー（ノンブルの右横コメント）に自動反映されます。
3. **「目次」**：章タイトルとページ番号を並べる目次ページです。
   - 「扉から見出しを自動抽出」または手動で項目を追加・編集できます。
   - 目次見出し（`目　次`）は空欄にすると非表示にできます。
   - レイアウトは「右揃え（標準）」「中央揃え（見出しを含めない）」「中央揃え（見出しを含める）」から選択可能です。
4. **「空白」**：挿絵や表1・表2等をあとから別ソフトで入れるために空けておくページです。
   - 本文は入りませんがノンブル等は反映されます。
   - 本文連動区間の途中に「空白」ページを挟んでも連動は切れず、空白ページを飛ばして前後の本文ページへ自動で本文が流し込まれます。

## 5. 本文内で使える組版記法

| 機能 | 記法例 | 説明 |
| :--- | :--- | :--- |
| **ルビ** | `｜漢字《かんじ》` または `\|漢字《かんじ》` | 親文字に対してルビを振ります（親文字が漢字のみの場合は `漢字《かんじ》` も可） |
| **縦中横** | `[縦中横:12]` | 指定した文字列を1マス内に横並びで配置します（※2〜3桁の半角数字や `!?` 等は自動縦中横設定も可） |
| **改ページ** | `[改ページ]` | 行頭に記述すると、以降の本文を次のページへ送ります |
| **改丁** | `[改丁]` | 行頭に記述すると、次の奇数頁（または設定により偶数頁）から開始するようページを送ります（`[改丁:奇数]` / `[改丁:偶数]` や全角コロン `［改丁：奇数］` も可） |

## 6. 環境・組版・入稿設定（右サイドバー各タブ）

> **※ 数値入力欄で「0」を入力した場合の仕様について**  
> 仕上がりサイズ・文字サイズ・1行文字数・行数・段間・余白（ノド/小口/天/地）などの「0では組版が成立しない数値設定項目」において、`0` や空欄を入力すると、レイアウト崩れを防ぐため**自動的にその項目の初期値（または最小下限値）へ戻る仕様**になっています（塗り足し幅、手動時の行間、目次天字下げ、扉タイトル位置微調整、欧文中心微調整など `0` が有効な項目では `0` として反映されます）。

### ■「ファイル」タブ（入力・出力）
- **印刷・入稿用画像出力**：
  - **「全ページ連番PSD (ZIP一括)」**：Photoshop や CLIP STUDIO PAINT 等でそのまま開ける連番PSDファイル（解像度情報 `0x03ED`・PackBits圧縮済み）をZIPで一括出力します。
  - **「全ページ連番PNG (ZIP一括)」** ／ **「現在表示中のページのみ単体PNG出力」**
  - カラーモード（グレースケール［白黒・8bitグレースケール形式］ / RGBカラー）、塗り足し幅（0 / 3 / 5mm）、トンボ（トリムマーク）付与を選択可能。
- **テキスト入出力**：
  - プレーンテキスト (`.txt`) / 青空文庫形式 (`.txt`) / Markdown (`.md`) の書き出し・インポート。
  - **※ インポート時のご注意**：外部テキスト（`.txt` / `.md`）を取り込む際、**`---`（ハイフン3つ）のみの行は章の区切り（連動区切り）とみなして新しい独立した本文区間へ分割されます**。場面転換の区切り線として `---` を使用している原稿を取り込む際はご注意ください。
- **保存・読込・初期化**：
  - 本文CSV保存・設定CSV保存・プロジェクト一括JSON保存/読込。
  - 各種ファイル（本文CSV / 設定CSV / プロジェクトJSON / 外部テキスト）の読み込み時には確認ダイアログが表示され、読み込んだ後も「元に戻す (`Ctrl+Z`)」で読み込み前の状態に戻せます。
  - 「初期サンプル原稿・デフォルト設定に戻す」「デフォルト設定に戻す（原稿内容は維持して設定のみ初期化）」「新規作成（白紙にする）」（誤操作防止の確認ダイアログ付き）。

### ■「サイズ」タブ
- **判型プリセット**：A6（文庫・105×148mm・標準）、新書判（103×182mm）、B6判（128×182mm）、A5判（148×210mm）、カスタムサイズ。
- **解像度**：600dpi（標準）/ 350dpi / 300dpi / 1200dpi、塗り足し幅、版面・トンボガイド表示切替。
- **段組み・行数・字数**：1段組（標準）/ 2段組、1行文字数（標準41字）、1段行数（標準18行）、行間・字送り自動調整。
- **余白設定**：ノド側（標準1.5cm）・小口側（標準1.0cm）・天あき（標準1.6cm）・地あき（標準1.2cm）。製本見開きに合わせて偶数頁は左がノド・奇数頁は右がノドに自動反転します。

### ■「文字」タブ
- **フォント自動検出＆Webフォント**：
  - 起動時にPC内のインストール済み主要システムフォントを自動検出し、全環境共通のWebフォント数種と合わせてプルダウンに表示します（デフォルト：游明朝 8.5pt）。PCに入っていないフォントは自動で隠れます。
- **任意のフォントファイルの追加読込**：
  - 手元のフォントファイル（`.ttf` / `.otf` / `.woff` / `.woff2`）を複数追加読み込むことができ、OpenTypeテーブルから日本語フォント名を自動抽出してプルダウンに追加します。
- **要素別・ページ別フォント設定**：
  - 「本文」「扉」「目次」「ノンブル」「ノンブル右横コメント」それぞれのフォント・文字サイズ・字間を個別に設定できます。
  - 「ページ毎にフォントを設定する」チェックをONにすると、エディタ上部にページ単位の個別フォント・サイズ変更欄が表示されます（デフォルトOFF）。

### ■「組版」タブ
- **ヘッダー・フッター設定**：
  - ノンブル表示位置（ヘッダー側 / フッター側）、開始ページ番号、フォントサイズ、奇数頁ノンブル右横コメントの間隔・参照元を設定可能。
  - 「扉ページではコメント文字列を非表示」「目次ページではコメント文字列を非表示」により、ノンブルを残したままタイトルコメントのみを非表示にできます。
- **禁則処理と行末調整**：行頭・行末禁則、ぶら下げ組 / 追い出し / 追い込み（行末に `。」` 等の禁則文字が連続する場合も2文字目が次行頭に来ないよう一体処理）。
- **縦中横と欧文処理**：半角数字（2〜3桁）や感嘆符（`!?` / `!!`）の自動縦中横、欧文処理（使用中フォントの実測幅に基づくプロポーショナル90度回転 / 略語スマート判定 / 1文字縦並び、英単語途中の改行禁止、和欧間アキ量、欧文サイズ比率・中心微調整）。
- **約物処理・改丁制御**：2倍ダッシュ（`――`）・三点リーダー（`……`）の隙間なし連結描画、カギ括弧や句読点のアキ量調整、`！`・`？` 直後の全角空白自動補完、改丁基準頁（奇数頁 / 偶数頁）。

### ■「UI設定」タブ
- **UI色調設定**：墨色ダーク（標準）/ 生成り和紙 / 琥珀セピア / 群青ミッドナイト / 深緑モダン / カスタム配色。
- **上部情報バー表示設定**：「日時・締切」「全ページ合計」「純粋文字数・空白改行除外」「400字詰換算」の個別表示／非表示切替。
- **進捗・締切ゲージの色調設定**：今日・今月経過ゲージおよび締切残り時間ゲージ（通常・50%未満・20%未満）の配色カスタマイズ。
- **ショートカットキーの設定**：主要操作に任意のショートカットキーを割り当て可能（初期状態は本文CSV保存＝`Ctrl+S` のみ設定）。
- **環境・組版設定のCSV保存・読込**。

## 7. ファイル構成と技術仕様

外部フレームワークやサードパーティ製ライブラリに依存しない **Vanilla JavaScript (HTML5 / CSS3 / Canvas 2D API)** で実装されています。

```text
tategaki-novel-editor/
├── index.html        # メイン画面構造・UI・ヘルプモーダル
├── README.md         # 本ドキュメント
├── LICENSE           # MITライセンス全文
├── css/
│   └── styles.css    # スタイルシート・テーマカラー変数・レスポンシブ制御
└── js/
    ├── state.js      # デフォルト設定・フォント検出・サンプル原稿定義
    ├── counter.js    # 多様な文字数カウント（純粋 / 空白除外 / 実文字数 / 400字詰換算）
    ├── typesetter.js # 縦書き組版エンジン・Canvas 2D 高解像度レンダラー
    ├── exporters.js  # PSD / PNG / TXT / 青空文庫 / Markdown / CSV / JSON 入出力エンジン
    └── app.js        # UIコントローラー・連動ページ割り・Undo・検索・ショートカット管理
```

> **※ フォントのライセンスに関するご注意**  
> 本ツール自体はフォントファイルを同梱しておらず、お使いの環境（OSまたはWebフォント、ユーザー自身が読み込んだフォントファイル）を参照して描画します。任意のフォントファイルを読み込んで同人誌印刷や頒布物に利用する場合は、各フォントの使用許諾規約（商用・有償頒布の可否など）をご自身でご確認ください。
