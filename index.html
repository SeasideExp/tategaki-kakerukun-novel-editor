縦書き同人小説書けるくん (Ver.1.00) - ヘルプ / 機能ガイド
======================================================================

【0. はじめに】
このテキストエディタは、作者（しーさいど）が既存のテキストエディタの仕様に納得行っていなかったので自分で作ったものです。テキストエディタ作成にあたってはＡＩを全面活用しています（Google Gemini4Argon）。「本文を書き出す」事のみを想定しており、同人誌として仕上げる場合、表紙や挿絵は別のソフトを使う想定です。そのため、オールインワンではないのは仕様となっています。

----------------------------------------------------------------------
【1. 概要・データ保持・プライバシー仕様について】
----------------------------------------------------------------------
■ 概要
「縦書き同人小説書けるくん」は、ブラウザ上で縦書きの右綴じ見開きプレビューをリアルタイムに確認しながら小説を執筆し、印刷所入稿・DTP編集向けの連番PSD / 連番PNGやテキストファイルを出力できる小説執筆エディタです。

■ データの保持と「セーブ」の推奨について（重要）
執筆中の原稿や設定内容は、お使いのブラウザ内のストレージ（LocalStorage／ブラウザキャッシュ領域）に自動的に保持される仕組みになっており、ページを再読み込みしても続きから作業できます。
ただし、ブラウザ内のキャッシュ領域で保持しているため、ブラウザの「キャッシュ・閲覧データ削除（サイトデータの消去）」を行ったり、シークレット（プライベート）ウィンドウを閉じたりすると、保持されていたデータが消えてしまう恐れがあります。
大切な原稿の消失を防ぐため、画面右上の「セーブ」ボタン（ショートカット: Ctrl+S）から、こまめにCSVファイルとしてPC等のローカル環境へ保存しておくことを推奨します。

■ AI非学習・外部へのデータ非送信について
本ツールは、文字入力・組版計算・プレビュー描画・ファイル入出力を含むすべての処理を、お使いのブラウザ内（ローカル環境）のみで完結させる仕様です。
執筆した小説本文や設定データが外部のサーバーへ送信されることは一切なく、AIの学習データとして利用・収集されることもありません。安心して執筆にご利用いただけます。

----------------------------------------------------------------------
【2. 画面構成と基本操作】
----------------------------------------------------------------------
■ 上部ヘッダー
・日付・経過ゲージ・締切ゲージ：
  現在の日付、今日/今月の経過率(%)、および設定した締切日時までの残り時間(%)をゲージ表示します。「締切未設定（または締切ゲージ）」をクリックすると締切日時を設定できます。
・全ページ合計カウンター：
  「純粋文字数」「空白・改行除外」「実文字数（ルビ・制御記法除外）」「400字詰原稿用紙換算枚数」をリアルタイム集計します（「UI設定」タブから各表示のON/OFF切替が可能）。
・セーブ / ロード：
  右上の「セーブ」（初期ショートカット: Ctrl+S）で全ページの原稿データをCSVファイルとして保存、「ロード」で保存した本文CSVファイルを読み込みます。

■ 左ペイン：執筆エディタ
・エディタとプレビューの境界バー（中央の縦線）はドラッグして任意の幅に調整できます（ダブルクリックで標準幅にリセット）。
・ページ属性表示：
  現在表示中ページの属性（「本文」「扉」「目次」「空白」）を表示します。
・本文連動区間：
  連続する「本文」ページ（間に「空白」ページを含む場合も連動維持）は1つの連動区間として繋がっており、文字の入力・削除に応じて自動でページが増減・折り返しされます。
  章ごとに独立させたい場合は「✂カーソル位置で連動を区切る」「＋新規連動区間を追加」等で区間を分けられます。
・執筆補助ツールバー：
  「元に戻す(Ctrl+Z)」「ルビ挿入」「縦中横」「ダッシュ(――)」「三点リーダー(……)」「[改ページ]」「[改丁]」のワンクリック挿入、および本文内キーワード連続検索（一致箇所のハイライト＆該当頁ジャンプ）が可能です。
・エディタ下部チェック機能：
  -「割付ページ別の背景色表示」：ONにすると、テキストエリア内でどこからどこまでが何ページ目（P.1, P.2...）に入るかを背景色とバッジで視覚化します（デフォルトOFF）。
  -「文頭1字下げチェック」：段落先頭の全角空白（　）忘れを自動検知し、該当行へのジャンプやワンクリック補完ができます。

■ 中央ペイン：プレビュー表示
・見開きプレビュー（常時「右綴じ見開き」：左＝奇数頁、右＝偶数頁）
・単ページ表示
・9ページグリッド俯瞰（ドラッグ＆ドロップでページ順序の入れ替えが可能）
・◀ / ▶ ボタン（またはプレビュー操作時のキーボード ← / → キー）でページ送りが可能です。

■ 下部ドック：ページ管理（クリックで開閉）
・ページの追加（＋本文頁 / ＋扉頁 / ＋目次頁 / ＋空白頁）、前後の順序入替、複製、削除が行えます。
・カウンター対象ページ選択：
  サムネイル左上のチェックボックス（または「全ページ選択」「現在の頁のみ選択」「選択解除」）で選択したページだけの文字数合計を「選択ページ計」に算出できます（初期状態は未選択）。

【3. 4つのページ属性について】
----------------------------------------------------------------------
1.「本文」：小説本文を流し込む標準ページです。
2.「扉」　：小説タイトル（表題）・副題・著者名・備考を配置するページです。
  - 表題の上下位置（天からの距離 mm）・左右位置（横微調整 mm）を数値で微調整できます。
  - ここに入力した「小説タイトル」は、奇数ページのヘッダー（ノンブルの右横コメント）に自動反映されます。
3.「目次」：章タイトルとページ番号を並べる目次ページです。
  -「扉から見出しを自動抽出」または手動で項目を追加・編集できます。
  - 目次見出し（目　次）は空欄にすると非表示にできます。
  - レイアウトは「右揃え（標準）」「中央揃え（見出しを含めない）」「中央揃え（見出しを含める）」から選択可能です。
4.「空白」：挿絵等をあとから別ソフトで入れるために空けておくページです。
  - 本文は入りませんがノンブル等は描画されます。
  - 本文連動区間の途中に「空白」ページを挟んでも連動は切れず、空白ページを飛ばして前後の本文ページへ自動で本文が流し込まれます。

----------------------------------------------------------------------
【4. 本文内で使える組版記法】
----------------------------------------------------------------------
・ルビ　　： ｜漢字《かんじ》 または |漢字《かんじ》
・縦中横　： [縦中横:12] （※2〜3桁の半角数字や !? 等は自動縦中横設定も可）
・改ページ： [改ページ] （次のページへ送る）
・改丁　　： [改丁] （次の奇数頁または偶数頁へ送る）

【5. 環境・組版・入稿設定（右サイドバー各タブ）】
----------------------------------------------------------------------
■「ファイル」タブ（入力・出力）
・印刷・入稿用画像出力：
  -「全ページ連番PSD (ZIP一括)」：PhotoshopやCLIP STUDIO等でそのまま開ける連番PSDを出力。
  -「全ページ連番PNG (ZIP一括)」／「現在表示中のページのみ単体PNG出力」
  - カラーモード（印刷所入稿用 K100%グレースケール / RGB）、塗り足し幅（0 / 3 / 5mm）、トンボ付与を選択可能。
・テキスト入出力：
  - プレーンテキスト(.txt) / 青空文庫形式(.txt) / Markdown(.md) の書き出し・インポート。
・保存・読込・初期化：
  - 本文CSV保存・設定CSV保存・プロジェクト一括JSON保存/読込。
  -「初期サンプル原稿・デフォルト設定に戻す」「新規作成（白紙にする）」（確認ダイアログ付き）。

■「サイズ」タブ
・判型プリセット：A6（文庫・標準）、新書判、B6判、A5判、カスタムサイズ。
・解像度（600dpi標準 / 350dpi / 300dpi / 1200dpi）、塗り足し幅、版面・トンボガイド表示切替。
・段組み（1段 / 2段）、1行文字数（標準41字）、1段行数（標準18行）、行間・字送り自動調整。
・余白設定：ノド側（標準1.5cm）・小口側（標準1.0cm）・天あき（標準1.6cm）・地あき（標準1.2cm）。

■「文字」タブ
・起動時にPC内のインストール済み主要システムフォントを自動検出し、全環境共通のWebフォント数種と合わせてプルダウンに表示します（デフォルト：游明朝 8.5pt）。
・任意のフォントファイル（.ttf / .otf / .woff / .woff2）を複数追加読み込むことができ、追加後はそのフォント名で選択可能です。
・「本文」「扉」「目次」「ノンブル」「ノンブル右横コメント」それぞれのフォントを個別に設定できます。
・「ページ毎にフォントを設定する」チェックをONにすると、エディタ上部にページ単位の個別フォント・サイズ変更欄が表示されます（デフォルトOFF）。

■「組版」タブ
・ヘッダー・フッター設定：
  - ノンブル表示位置（ヘッダー側 / フッター側）、開始ページ番号、フォントサイズ、奇数頁ノンブル右横コメントの間隔・参照元を設定可能。
  -「扉ページではコメント文字列を非表示」「目次ページではコメント文字列を非表示」により、ノンブルを残したままタイトルコメントのみを非表示にできます。
・禁則処理と行末調整（ぶら下げ組 / 追い出し / 追い込み）。
・縦中横（2〜3桁数字、!?等の自動縦中横）と欧文処理（プロポーショナル90度回転 / 略語スマート判定 / 1文字縦並び、ワードラップ、和欧間アキ量）。
・約物処理（2倍ダッシュ・三点リーダーの連結描画、括弧や句読点のアキ量、！？直後の全角空白自動補完）および改丁基準頁（奇数頁 / 偶数頁）。

■「UI設定」タブ
・カラーテーマ切替（墨色ダーク / 生成り和紙 / 琥珀セピア / 群青ミッドナイト / 深緑モダン / カスタム配色）。
・上部情報バー（「日時・締切」「全ページ合計」「純粋文字数・空白改行除外」「400字詰換算」）の表示／非表示切替。
・上部バーの経過率・締切ゲージの色設定。
・ショートカットキーの設定（主だった操作に任意のキーを割り当て可能。初期状態は本文CSV保存＝Ctrl+Sのみ設定）。
・環境・組版設定のCSV保存・読込。
